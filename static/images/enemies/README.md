# Enemy pictures

Each card shows `static/images/enemies/<slug>.<ext>` if that file exists, otherwise the faction icon.
Supported extensions: .webp, .png, .jpg, .jpeg, .gif. No code or database change is needed:
download the file from the wiki page, rename it as below and drop it in this folder.
Admins can also upload a picture from the Add/Edit entry form.

Pictures are © Arsi "Hakita" Patala / New Blood Interactive, taken from the official
ULTRAKILL wiki (ultrakill.wiki.gg) for a non-commercial university project; the site footer credits them.
